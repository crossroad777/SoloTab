# ADR-004: ベンチマークと本番パイプラインのコードパス乖離

ステータス: 承認済み（Accepted）

コンテキスト:
  360曲ベンチマークおよびミニベンチマークは `pipeline.py` をバイパスし、
  MoE FT の純粋な性能を測定している。一方、本番 Web API は
  Basic Pitch + MoE のアンサンブル（`pipeline.py`）を使用している。
  2026年のラウンドトリップテストで、`pipeline.py` のアンサンブル融合ロジック
  （`BP_ONLY_THRESHOLD`）が正しいノートを大量に削除していたことが発覚。

決定:
  ベンチマークと本番パイプラインが異なるコードパスを測定していることを
  公式に記録する。`pipeline.py` の修正は、既存ベンチマークでは検出されない
  ため、別途ラウンドトリップテストまたはフルパイプラインベンチマークで
  検証する必要がある。

結果:
  `pipeline.py` の修正時には、ラウンドトリップテストを必ず実行すること。
  将来的に、本番パイプライン（`pipeline.py`）を通すベンチマークの構築を検討する。
