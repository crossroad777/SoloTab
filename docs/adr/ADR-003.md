# ADR-003: H/P 検出の構造的限界と将来フェーズ化

**ステータス:** 承認済み（Accepted）

## コンテキスト
H/P（ハンマリング/プリング）の検出を試みたが、以下の結果に終わった。
- Layer 1（ルールベース）: Precision 14%、normal FPR 15.58%
- CNN には H/P クラスが存在しない（IDMT アノテーションに存在しない）
- GP5コーパスの特徴分析で「H/Pと速いピッキングの分布が完全オーバーラップ」であることを数学的に証明（Velocity比は99.8%が1.000）

## 決定
記号データだけではH/P検出は原理的に不可能と判断。
現在はルールベースを物理的に無効化。
将来の Phase B-1b として、実録音データ収集フェーズを独立計画。

## 結果
偽陽性の本番混入を完全に防止。v1.0の安全性を担保。
