# ADR-005: CNN確信度ベースの弦割り当てハード保護

## 背景
E2EパイプラインのString Accuracy（弦割り当て精度）が68.95%で頭打ちになっていた。エラー分解分析（error_decomposition.py）の結果、弦割り当てエラーの92.2%（189ノート）が「CNN分類器は正解の弦を最も高い確率で予測していたが、Viterbi DPの遷移ペナルティ（弦移動ペナルティ等）によって誤った弦に上書きされている（Category B1エラー）」ことが判明した。これは、論文における「CNN-first、Viterbiはリファインメントのみ」という設計思想と実装が乖離していることを示している。

## 決定事項
Viterbiによる過剰な上書きを防止するため、CNNの予測確率（確信度）に基づく3段階の動的重み付け（保護）を導入した。

1. **ハード保護モード (確信度 >= 0.90)**:
   - CNNの予測弦候補以外をViterbiの探索空間からプルーニングし、CNNの予測を強制的に採用する（ハードロック）。
2. **強保護モード (確信度 0.80 - 0.90)**:
   - CNNのボーナス重みを100.0に引き上げ、遷移ペナルティを確実に上回るようにする。
3. **バランス/フォールバックモード (確信度 < 0.80)**:
   - 従来通り、確信度に応じて重みを30.0/50.0/10.0と段階的に適用する。

## 結果
この変更により、E2EパイプラインにおけるString Accuracyは `68.95% → 74.85%` へと大幅に向上（+5.9%）した。ピッチが正しく検出されたノートに限定すれば、弦割り当て精度は約89%に達し、高域（C4以上）での隣接弦への誤った引き寄せも33%削減された。

## リスクと将来の検討事項
全ノートの92.8%が「ハード保護モード（CNN確信度 >= 0.90）」に該当している。これは、現在のE2Eパイプラインが実質的に「CNN分類器の単体出力」で動作していることを意味する。
* **ドメイン外データでのリスク**: GuitarSet（CNNの学習データと同一ドメイン）では高い精度を誇るが、GuitarSet外の音源（ユーザーの実演奏、ナイロン弦、異なる録音環境）では、未知データに対するCNNのLOPO精度（80.4%）が適用される。ハード保護モードは「CNNが間違えていてもViterbiが修正できない」ことを意味するため、未知の環境ではかえって精度を落とす裏目に出るリスクがある。
* **将来のアクション**: 「プレイヤー種別・録音環境に応じた保護強度の動的切替」や、「ユーザーフィードバックに基づくハード保護のON/OFF切り替え」を検討事項として残す。
