# ADR-002: テクニック記号と運指エンジンの完全分離

**ステータス:** 承認済み（Accepted）

## コンテキスト
`finger_assigner.py` のv13.0には、テクニック依存のコスト関数（`w_tech_hammer_pull_bonus` 等）が組み込まれている。しかし、誤検出されたテクニックラベルが運指計算に流入すると、+50.0 のペナルティが運指全体を歪める非対称なリスクがある。

## 決定
当面は `enable_technique_fingers = False` を維持し、テクニック記号は譜面出力（GP5/MusicXML）のみに使用。運指反映は、Precision ≥ 0.90 が証明された将来のフェーズに委ねる。

## 結果
360曲 Regression ゼロ。テクニック記号の誤検出がコアパイプラインを汚染するリスクを物理的に排除。
