## 3. 特定・根絶された3大構造バグとブレークスルー

### ① The Silent Dropout（データローダーの波形スキップバグ）
- **原因**: データローダーで `.wav` 不在時に例外を出さず静かにスキップしていたため、GuitarSet生波形（556トラック）が過去の学習から完全に抜け落ちていた。
- **解決**: `.pt` CQTキャッシュのフォールバック機構を導入し、556トラック全量を投入して全7ドメインモデル（MoE）を完全再学習。A1エラー（見逃し）が 149個 $\rightarrow$ 87個（41.6%）激減。

### ② The Frozen Randomness（乱数シード固定バグ）
- **原因**: DataLoader のマルチプロセスによりエポック間で乱数シードが固定され、毎エポック同一のデータ拡張パターンを暗記（過剰適合）していた。
- **解決**: エポックごとの動的シード再生成と Gradient Clipping（1.0）を導入し、真の汎化性能を獲得。

### ③ The Viterbi Override（DPによるCNN予測の強制上書き）
- **原因**: 運指決定の Viterbi DP コストが過大で、CNNが95%以上の確信度で正解弦を予測していても近隣弦に強制変更（B1エラー）していた。
- **解決**: CNN確信度 $\ge 0.90$ で Viterbi 遷移コストを無効化する「CNNハードプロテクト」を実装。String Accuracy が 75% $\rightarrow$ **82.05%** に飛躍。

### ④ 音楽理論・倍音構造フィルタ（Pass 2 v3）
- **知見**: A2エラーの 52.3% がオクターブ（±12/24）および5度（±19）の高次倍音で、46%が和音の最高音に集中。
- **解決**: 同時発音グループ（$\Delta t \le 50$ms）内で、基本音より弱くコード外の高次倍音を自動除去。CNNハードプロテクトとコードトーン（$S_{harmonic} \ge 0.30$）は完全保護。

### ⑤ $BP\_ONLY\_THRESHOLD = 0.40$（黄金比の特定）
- **解決**: MoEカバレッジが高い場合、Basic Pitch単独ノートの採用閾値を `0.40` に設定。見逃し（105個）と過剰検出（177個）の完璧なトレードオフを実現。
