# SoloTab H/P 解析用 データ収集・録音要件書

本ドキュメントは、AIギター採譜システム「SoloTab」のハンマリング・オン / プリング・オフ (H/P) 検出モデル（Stage 2: アタックトランジェント検証）を学習させるための、極めて重要な機械学習用データセット作成の要件書です。

## 1. 録音環境・機材の要件（ドライ音の徹底）
AIが波形の微小なアタック成分（トランジェント）を解析するため、音響的ノイズや付加的な残響を完全に排除する必要があります。

- **DI録音（ライン録音）を強く推奨**: ギターをオーディオインターフェースに直接接続（Hi-Z入力）し、生の波形を録音してください。
- **アンプマイク録音の場合**: アンプのスピーカーに近接マイク（オンマイク）を立て、部屋鳴り（ルームリバーブ）が一切入らないようにしてください。
- **サンプリングレート / ビット深度**: `44.1kHz` または `48kHz` / `24-bit` 以上。
- **フォーマット**: `.wav` または `.flac`（非圧縮。MP3は不可）。

## 2. 音作り（エフェクト）の厳守事項
> [!CAUTION]
> 以下のエフェクトは、アタック成分を平滑化・拡散させるため、AIの学習を決定的に阻害します。**必ずOFF**にしてください。

- **空間系・モジュレーション系は完全OFF**: リバーブ、ディレイ、コーラス、フランジャー等。
- **コンプレッサーは完全OFF**: アタックトランジェントの差異を維持するため、コンプレッションは厳禁です。
- **歪み（オーバードライブ等）**: クリーン〜クランチ程度の非常に軽い歪みであれば許容されますが、アタックが潰れるディストーションは避けてください。

## 3. 演奏フレーズと「対比データ」の重要性
AIに「これがH/P」「これがピッキング」という違いを学習させるため、同梱の譜面（GP5）には、**全く同じフレーズを2パターン（H/P版とオールピッキング版）**収録しています。

- **フレーズA（H/P指定版）**: スラー記号に従ってレガートで演奏してください。
- **フレーズB（All Picking指定版）**: Aと全く同じ音符・タイミングを、すべてオルタネイトピッキングで演奏してください。
- **【重要】ピッキング強度の統一**: Aパターンのピッキング音と、Bパターンのピッキング音で、強さ（アタック感）を意図的に変えないでください。自然なダイナミクスでの演奏をお願いします。

## 4. 収録フレーズのバリエーション
テスト譜面には、AIが様々な条件下でH/Pを分離できるよう、以下の4軸を網羅したフレーズが用意されています。これらはすべてAIのロバスト性（堅牢性）を担保するために計算された構成です。

1. **スケールとフレージング**: マイナー・ペンタトニック（H/P密集）、3ノート・パー・ストリング（弦移動）、クロマチック（アタック減衰の極限）。
2. **弦の種類**: プレーン弦（1-2弦: トランジェントが鋭い） vs 巻弦（3-6弦: プリング特有のスクラッチノイズが発生する）。
3. **音程差（インターバル）**: 半音（1フレット）、全音（2フレット）、広域ストレッチ（3〜4フレット）。
4. **BPM帯**: Slow (80 BPM)、Mid (110 BPM)、Fast (150 BPM)。

## 5. 納品物
- メトロノーム（クリック）に合わせて演奏したオーディオファイル（`.wav`）。
  ※クリック音は**オーディオファイルに絶対に混入しない**ようにしてください（密閉型ヘッドホン使用推奨）。
- AパターンとBパターンは、同じファイルの連続したテイクでも、別ファイルに分けていただいても構いません。
