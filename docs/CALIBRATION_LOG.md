## 2. 診断と結論：下流調整の限界

1. **下流調整の打ち止め**:
   - `universal_quantizer.py`（リズム量子化）や `string_assigner.py`（運指最適化）など、AMT下流のルールベース・DPによる調整は限界（収穫逓減）に達した。
2. **残差の本質的原因**:
   - 残る差分（イントロ弱音の漏れ、オクターブ誤り、リズムの微小な揺らぎ）はすべて**上流（AMTの倍音・欠落、実録音のオンセットジッタ、ビートトラッカーの位相）**に起因する。
   - 下流でこれ以上無理に閾値をこじ開けると、ゴーストノートの大量混入（TASK-939の症状）や別楽曲（Romance等）への副作用を引き起こす。

## 3. 採用決定：道A（下書き＋手直しエディタ）

- SoloTabのAIパイプラインは**「高精度な初稿（下書き）」**を出力する責務に集中する。
- 演奏上のニュアンスや微小な修正は、直感的なフロントエンドエディタ（`TabView.jsx` / `PATCH /result/{id}/notes/{idx}`）による **Human-in-the-Loop** 編集で完成させる。
